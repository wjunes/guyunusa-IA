# Windows 11 - Pantalla negra al iniciar

## Descripción
Guía de diagnóstico progresivo para el problema indicado.

## Síntomas
- El usuario reporta falla principal relacionada con video.
- El problema puede ser intermitente o persistente.
- Puede afectar una o varias aplicaciones/dispositivos.

## Causas posibles
- Configuración incorrecta.
- Controlador/servicio no operativo.
- Cambio reciente del sistema o actualización.

## Diagnóstico (preguntas guiadas)
1. ¿Qué sistema operativo estás usando?
2. ¿Desde cuándo ocurre?
3. ¿Afecta a todas las apps/dispositivos?
4. ¿Hubo actualización reciente?
5. ¿Aparece algún error específico?

## Solución básica (segura)
1. Verificar configuración principal.
2. Reiniciar app/dispositivo implicado.
3. Confirmar si el síntoma persiste.

## Solución intermedia
1. Revisar servicio/controlador relacionado.
2. Ejecutar herramienta de diagnóstico del sistema.
3. Reprobar el caso.

## Solución avanzada
1. Reinstalar/rollback controlado del componente relacionado.
2. Validar logs/estado técnico.
3. Confirmar resultado final.

## Verificación
- El síntoma principal desaparece.
- La función vuelve a operar con normalidad.
- No se reproducen errores al repetir la prueba.

## Cuándo escalar
Escalar si persiste tras los pasos o hay indicios de fallo físico.

## Riesgos / advertencias
- No ejecutar acciones destructivas sin backup.
- No descargar drivers de sitios no oficiales.
- Detener procedimiento ante señales eléctricas/físicas.
