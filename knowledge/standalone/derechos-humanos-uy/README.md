# derechos-humanos-uy

Dominio del conocimiento sobre **derechos humanos en Uruguay** para la Base Nacional de Conocimiento (BNC-UY).

## Descripción

Cubre el marco institucional, la historia de los derechos humanos, la dictadura cívico-militar (1973-1985), la justicia transicional, los derechos de grupos específicos (mujeres, infancia, LGBTIQ+, afrodescendientes, pueblos indígenas, migrantes) y el sistema carcelario.
