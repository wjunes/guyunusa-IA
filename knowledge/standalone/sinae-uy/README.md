# sinae-uy — Sistema Nacional de Emergencias y Gestión Integral del Riesgo

## Descripción del dominio

`sinae-uy` es el dominio de la Base Nacional de Conocimiento Uruguay (BNC-UY) dedicado al **Sistema Nacional de Emergencias (SINAE)** y a la **Gestión Integral del Riesgo de Emergencias y Desastres (GIRD)** en Uruguay.

El dominio responde principalmente a la pregunta: *¿Cómo funciona Uruguay para prevenir, reducir, prepararse, responder y recuperarse frente a riesgos, emergencias y desastres?*

## Fuente principal

Portal oficial del SINAE: https://www.gub.uy/sistema-nacional-emergencias/
