# bibliotecas-uy — Bibliotecas y Sistema Bibliotecario de Uruguay

## Descripción del dominio

Este dominio cubre el **sistema bibliotecario uruguayo**: la Biblioteca Nacional, el sistema de bibliotecas de la Udelar, las bibliotecas públicas departamentales y municipales, las bibliotecas escolares (ANEP), las bibliotecas especializadas de organismos públicos, el marco legal (depósito legal, derechos de autor), la profesión bibliotecológica y los procesos de digitalización y acceso abierto.
