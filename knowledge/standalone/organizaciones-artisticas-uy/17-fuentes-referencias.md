## Notas metodológicas

### Términos de búsqueda utilizados

Las siguientes variantes fueron empleadas sistemáticamente:
- `[sigla] Uruguay`, `[sigla] Uruguay sitio oficial`, `[nombre completo] Uruguay`
- `gremio [disciplina] Uruguay`, `sindicato [disciplina] Uruguay`, `asociación [disciplina] Uruguay`
- `[sigla] Uruguay MTSS`, `[sigla] Uruguay MEC`, `[sigla] Uruguay INAE`

### Estados documentales utilizados

| Estado | Significado |
|---|---|
| **VIGENTE** | Actividad confirmada en fuentes recientes (2020-2026) |
| **VIGENTE CON CAMBIOS** | Vigente pero con modificaciones recientes al marco o denominación |
| **HISTÓRICA** | Con actividad pasada documentada; estado actual no verificado |
| **DISCONTINUADA** | Disuelta o sin actividad confirmada |
| **NO CONFIRMADA** | La entidad no pudo ser verificada en ninguna fuente |
| **PENDIENTE DE VALIDACIÓN** | Datos específicos requieren verificación adicional directa |

### Criterio "no encontrado ≠ inexistente"

La baja presencia web de una organización no implica que no exista. Uruguay tiene muchas organizaciones con actividad real pero poca documentación digital. Para las organizaciones con baja presencia web se indica "PENDIENTE DE VALIDACIÓN" o "NO CONFIRMADA" según el grado de evidencia disponible.
