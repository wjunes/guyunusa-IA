# periodismo-deportivo-uy

Dominio de conocimiento sobre el periodismo deportivo uruguayo. Cubre la historia, evolución, medios, publicaciones, periodistas, comunicadores, géneros, prácticas, ética y lenguaje del periodismo deportivo en Uruguay desde sus orígenes hasta la actualidad.

> Este dominio tiene propósito exclusivamente informativo y educativo. No constituye asesoramiento profesional ni reemplaza la consulta de fuentes primarias. Para información deportiva de actualidad (resultados, fichajes, calendarios), utilizar búsqueda web en tiempo real.

---

## Principio rector

**El deporte describe el acontecimiento. El periodismo deportivo describe cómo ese acontecimiento fue informado, interpretado y comunicado.** Este dominio cubre la segunda dimensión. Los hechos deportivos pertenecen a dominios como `deportes-uy`, `futbol-uy` o `basquet-uy`. Las afirmaciones históricas no verificables se presentan como tales.
