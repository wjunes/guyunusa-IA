# aduanas-uy

Dominio de conocimiento sobre las aduanas y el comercio exterior de la República Oriental del Uruguay. Cubre la Dirección Nacional de Aduanas (DNA), el marco jurídico aduanero, la clasificación arancelaria, el Arancel Externo Común del MERCOSUR, los regímenes aduaneros especiales, las zonas francas, el control fronterizo y los procedimientos del comercio exterior.

> Este dominio tiene propósito exclusivamente informativo y educativo. No constituye asesoramiento aduanero ni jurídico. Para situaciones específicas, debe consultarse un despachante de aduana habilitado o un asesor jurídico.
