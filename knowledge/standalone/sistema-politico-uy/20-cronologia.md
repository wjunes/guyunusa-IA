# Cronología del sistema político uruguayo (1830–2026)

## El siglo XIX (1830–1903)

| Año | Hecho |
|---|---|
| 1830 | Primera Constitución; sufragio restringido; primer presidente (Rivera) |
| 1834 | Primer cambio de gobierno: Oribe sucede a Rivera |
| 1839–1851 | Guerra Grande: blancos vs. colorados con intervención extranjera |
| 1865 | Inicio de la hegemonía Colorado (casi ininterrumpida hasta 1958) |
| 1876–1890 | El militarismo: Latorre y Santos |
| 1877 | Reforma educativa vareliana |
| 1896 | Creación del BROU |

## El batllismo y las primeras reformas (1903–1958)

| Año | Hecho |
|---|---|
| 1903–1907 | Primera presidencia de Batlle y Ordóñez |
| 1904 | Fin de las guerras civiles (derrota de Saravia) |
| 1907 | Abolición pena de muerte; divorcio legal |
| 1911–1915 | Segunda presidencia de Batlle y Ordóñez |
| 1915 | Jornada de 8 horas |
| 1917–1918 | Nueva Constitución: sufragio universal, laicismo, Consejo Nac. Adm. |
| 1932 | Voto femenino |
| 1933 | Golpe de Terra; nueva Constitución autoritaria |
| 1942 | Reforma constitucional que modera el período de Terra |
| 1952 | Constitución del colegiado pleno (9 miembros) |
| 1958 | Primer gobierno blanco en 93 años |

## Crisis y dictadura (1958–1985)

| Año | Hecho |
|---|---|
| 1958 | Gobierno del Partido Nacional |
| 1963 | Fundación del MLN-Tupamaros |
| 1966 | Constitución de 1967 aprobada; fin del colegiado |
| 1971 | Fundación del Frente Amplio; elecciones |
| 27/06/1973 | Golpe de Estado |
| Nov 1980 | Referéndum: 57% vota NO a la Constitución de los militares |
| Nov 1982 | Elecciones internas de los partidos |
| Ago 1984 | Pacto del Club Naval |
| 25/11/1984 | Elecciones: gana Sanguinetti (Colorado) |
| 01/03/1985 | Retorno a la democracia |
| Dic 1986 | Ley de Caducidad |

## La democracia restaurada (1985–2026)

| Año | Hecho |
|---|---|
| 1989 | FA gana Intendencia de Montevideo; Lacalle Herrera presidente |
| 1991 | MERCOSUR |
| 1992 | Referéndum: 72% revierte privatizaciones |
| 1996 | Reforma constitucional: balotaje e internas simultáneas |
| 2000 | Jorge Batlle presidente; crisis 2002 |
| 2004 | Tabaré Vázquez: primer gobierno del FA (51% primera vuelta) |
| 2007 | Reforma tributaria (IRPF) |
| 2009 | Voto en el exterior; creación de Municipios (Ley 18567) |
| 2010 | Gobierno Mujica; voto a los 16; Ley 18650 (Defensa) |
| 2012 | Despenalización del aborto |
| 2013 | Matrimonio igualitario; regulación cannabis |
| 2015 | Segundo gobierno Tabaré Vázquez |
| 2019 | Coalición Multicolor; Lacalle Pou gana el balotaje |
| Jul 2020 | Ley de Urgente Consideración (LUC) |
| Mar 2022 | Referéndum LUC: se mantiene (49,1%) |
| Dic 2023 | Referéndum reforma previsional: se mantiene (60%) |
| Nov 2024 | Yamandú Orsi (FA) gana balotaje |
| 01/03/2025 | Gobierno de Yamandú Orsi |
