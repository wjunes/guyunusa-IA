# sistema-politico-uy

Dominio BNC-UY: Sistema político del Uruguay

## Descripción

Documentación sobre el sistema político uruguayo: marco constitucional, poderes del Estado, partidos políticos, sistema electoral, democracia directa, gobierno departamental y municipal, sociedad civil y medios de comunicación. Cubre desde la Constitución de 1830 hasta el presente (2026).
