# tecnologia-uy

Dominio del conocimiento sobre **tecnología, software e innovación en Uruguay** para la Base Nacional de Conocimiento (BNC-UY).

## Descripción

Cubre la industria del software y su evolución, el ecosistema de startups, las instituciones del sector (AGESIC, ANII, CUTI, LATU, MIEM), el marco legal de incentivos, gobierno digital, ciberseguridad, inteligencia artificial, tecnologías emergentes, formación tecnológica y empresas de tecnología uruguayas con presencia internacional.
