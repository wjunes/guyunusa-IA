# Dominio BNC-UY: pesca-uy

## Descripción general

Dominio de conocimiento sobre el sector pesquero y la acuicultura en Uruguay. Cubre la estructura del sector (pesca industrial y artesanal), el marco jurídico (Ley 19.175, DINARA, CTMFM), las principales especies (merluza, calamar, corvina), la pesca artesanal costera y fluvial, la pesca industrial (flota, puertos), la acuicultura (mejillón), las exportaciones e industria de procesamiento, la gestión de recursos y el impacto ambiental, y la historia y perspectivas del sector.

**Nivel**: Tier 2 — actualización trimestral
**Archivos**: 8 archivos temáticos + este README
**Solapamiento principal evitado**: medio-ambiente-uy (gestión ambiental general), comercio-exterior-uy (exportaciones en general), industria-uy (procesamiento industrial general)

## Criterios de actualización (Tier 2 — trimestral)

Actualizar cuando:
- DINARA publica datos de capturas, cuotas o estado de stocks
- Uruguay XXI reporta variaciones en exportaciones pesqueras
- CTMFM fija nuevas cuotas para merluza o corvina
- Se producen cambios en el marco regulatorio (Ley 19.175, reglamentos)
- Inicio/cierre de temporadas de calamar patagónico
- Cambios significativos en el mercado internacional de productos pesqueros

## Reglas de solapamiento

Este dominio cubre **pesca extractiva y acuicultura** como actividades económicas primarias. No cubre:
- **medio-ambiente-uy**: la política ambiental general y los instrumentos de gestión transversales; este dominio cubre el impacto ambiental específico de la pesca y la gestión de stocks
- **comercio-exterior-uy**: las estadísticas y políticas de comercio exterior están en comercio-exterior-uy; este dominio cubre las exportaciones específicas del sector pesquero
- **industria-uy**: el procesamiento industrial general; este dominio cubre la industria de procesamiento pesquero
- **geografia-uy**: la oceanografía y geografía costera general; este dominio cubre el uso pesquero del mar uruguayo
