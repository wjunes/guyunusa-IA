# Dominio justicia-uy — Base Nacional de Conocimiento Uruguay

## Descripción

El dominio `justicia-uy` documenta el sistema de justicia de la República Oriental del Uruguay: su organización institucional, historia, competencias, actores, procedimientos generales y estadísticas. Está diseñado para su uso en sistemas RAG (Retrieval-Augmented Generation) y como base de conocimiento para estudiantes, investigadores, periodistas, funcionarios públicos y sistemas de inteligencia artificial.

## Objetivo

Proporcionar información factual, precisa y bien estructurada sobre el sistema judicial uruguayo, sin emitir interpretaciones normativas ni asesoramiento legal.

## Alcance

Este dominio cubre:
- Organización y estructura institucional del Poder Judicial y organismos vinculados
- Historia y evolución del sistema de justicia uruguayo
- Competencias y funciones de los órganos judiciales
- Actores del sistema: magistrados, fiscales, defensores, abogados y auxiliares
- Procedimientos generales (perspectiva institucional)
- Métodos alternativos de resolución de conflictos
- Transformación digital del sistema
- Estadísticas judiciales
- Cooperación internacional

## Lo que este dominio NO incluye

- Interpretación de normas jurídicas
- Asesoramiento legal o jurídico
- Jurisprudencia o doctrina jurídica
- Análisis de casos concretos
- Recomendaciones sobre estrategias procesales
