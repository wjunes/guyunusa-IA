# Dominio BNC-UY: juventud-uy

## Descripción general

Dominio de conocimiento sobre las políticas de juventud y la situación de los jóvenes (15-29 años) en Uruguay. Cubre el marco jurídico (Ley 18.216, CIDJ), el INJU y sus programas, mercado laboral juvenil (desempleo, informalidad, Primer Empleo Joven), jóvenes NiNi, salud mental (suicidio, consumo problemático), participación política, vivienda y emancipación, grupos juveniles en situación de vulnerabilidad (afrodescendientes, LGBTQ+, rurales, situación de calle), y perspectivas de futuro.

**Nivel**: Tier 2 — actualización trimestral
**Archivos**: 9 archivos temáticos + este README
**Solapamiento principal evitado**: niñez-adolescencia-uy (0-17 años), envejecimiento-adulto-mayor-uy (60+), educacion-uy (sistema educativo general), trabajo-empleo-uy (mercado de trabajo general)

## Criterios de actualización (Tier 2 — trimestral)

Actualizar cuando:
- INE publica ECH con datos de desempleo y NiNi juvenil
- INJU publica datos de cobertura de programas (Yo Estudio y Trabajo, Jóvenes en Red)
- MTSS reporta datos del Primer Empleo Joven

- Se producen cambios normativos relevantes para la juventud

## Reglas de solapamiento

Este dominio cubre **jóvenes (15-29 años)** y las políticas específicas para este grupo. No cubre:
- **niñez-adolescencia-uy**: NNA (0-17 años); hay superposición en 15-17 años (tratados en ambos); este dominio prioriza la perspectiva de inserción en empleo y educación media/terciaria
- **envejecimiento-adulto-mayor-uy**: adultos mayores (60+)
- **educacion-uy**: el sistema educativo en general está en educacion-uy; este dominio cubre el acceso, la desvinculación y los resultados educativos de los jóvenes
- **trabajo-empleo-uy**: el mercado de trabajo general está en trabajo-empleo-uy; este dominio cubre el empleo juvenil específicamente
- **salud-uy**: el sistema de salud general está en salud-uy; este dominio cubre la salud mental y los problemas de salud específicos de la juventud
