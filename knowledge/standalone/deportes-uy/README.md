# deportes-uy

Dominio del conocimiento sobre **deporte en Uruguay** para la Base Nacional de Conocimiento (BNC-UY).

## Descripción

Cubre el fútbol y su dimensión identitaria (AUF, La Celeste, Copa América, Nacional, Peñarol, jugadores históricos y contemporáneos), el rugby (Los Teros), y los deportes olímpicos uruguayos: atletismo, remo, ciclismo, vela, deportes de combate, natación, canotaje, tenis y deporte femenino. El dominio de básquetbol tiene cobertura independiente en `basquet-uy`.
