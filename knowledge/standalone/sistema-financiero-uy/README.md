# sistema-financiero-uy

Dominio de conocimiento sobre el sistema financiero de la República Oriental del Uruguay. Cubre la arquitectura institucional, los actores del sistema, la regulación y supervisión prudencial, los instrumentos financieros, la historia del sector y las principales crisis y reformas.

> Este dominio tiene propósito exclusivamente informativo y educativo. No constituye asesoramiento financiero, bancario ni de inversiones. Para situaciones específicas, debe consultarse un profesional habilitado.
