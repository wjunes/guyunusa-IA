# industria-uy

Dominio de conocimiento especializado sobre la industria uruguaya para el sistema BNC-UY.

## Descripción

Este dominio documenta la estructura, historia, sectores, empresas, empleo, inversión, competitividad, tecnología y política industrial del Uruguay. Cubre desde la agroindustria de exportación hasta las PYMES industriales del mercado interno, incluyendo el patrimonio industrial histórico.

**Tier**: 2 (actualización trimestral)
**Versión**: 1.0.0 (2026-09-08)
**Dominio relacionado**: comercio-exterior-uy, agro-uy, energia-uy, tecnologia-uy, biotecnologia-uy, medio-ambiente-uy, mineria-recursos-geologicos-uy, pesca-uy, patrimonio-industrial-uy, mipymes-emprendimiento-uy, trabajo-derecho-laboral-uy

## Criterio de actualización

Actualizar cuando existan cambios significativos en: inversiones industriales importantes, cierres o aperturas de plantas, nuevos sectores industriales, cambios en políticas de promoción, estadísticas oficiales nuevas de producción y empleo, o modificaciones regulatorias relevantes. No realizar búsquedas amplias sobre todos los subtemas en cada ciclo.

## Notas técnicas

- Los datos marcados con `> **[DATO DINÁMICO]**` son cifras variables que deben actualizarse desde las fuentes indicadas.
- Los datos estructurales (historia, instituciones, marcos normativos) son más estables y se actualizan solo cuando cambian de forma sustancial.
- Para evitar solapamiento: este dominio explica la actividad industrial como sistema productivo; los dominios especializados (agro-uy, energia-uy, etc.) explican en profundidad sus respectivas áreas.
