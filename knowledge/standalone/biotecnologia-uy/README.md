# Dominio BNC-UY: biotecnologia-uy

## Descripción general

Dominio de conocimiento sobre la biotecnología en Uruguay: investigación, aplicaciones productivas, marco regulatorio y ecosistema institucional. Cubre la biotecnología agropecuaria (INIA, OGM, mejoramiento vegetal), el CUDIM (ciclotrón, radiofármacos, medicina nuclear), la biotecnología en salud humana (biofármacos, Instituto Pasteur), la regulación de OGM y bioseguridad, las vacunas veterinarias (DILAVE), el ecosistema institucional (ANNI, UdelaR, PEDECIBA), y las perspectivas (bioeconomía, CRISPR, inteligencia artificial).

**Nivel**: Tier 2 — actualización trimestral
**Archivos**: 7 archivos temáticos + este README
**Solapamiento principal evitado**: industria-uy (industria manufacturera general), agro-uy (producción agropecuaria en general), salud-uy (sistema de salud general), tecnologia-uy (TIC y software)

## Reglas de solapamiento

Este dominio cubre **biotecnología** como disciplina transversal aplicada a salud, agro y ambiente. No cubre:
- **agro-uy**: la producción agropecuaria en general; este dominio cubre solo las aplicaciones biotecnológicas al agro
- **industria-uy**: la industria manufacturera general; este dominio cubre la industria biofarmacéutica y de diagnóstico
- **salud-uy**: el sistema de salud en general; este dominio cubre las aplicaciones biotecnológicas a la salud
- **tecnologia-uy**: TIC, software y tecnología digital; este dominio cubre biotecnología (biología + tecnología), no tecnología digital
- **medio-ambiente-uy**: la gestión ambiental general; este dominio cubre la regulación de bioseguridad y la biotecnología ambiental incipiente
