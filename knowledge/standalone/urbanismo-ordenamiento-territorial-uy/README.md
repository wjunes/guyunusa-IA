# Dominio BNC-UY: urbanismo-ordenamiento-territorial-uy

## Descripción general

Dominio de conocimiento sobre el ordenamiento territorial y el urbanismo en Uruguay. Cubre el marco jurídico (Ley 18.308 de 2008), la DINOT y las instituciones, la clasificación del suelo (urbano/suburbano/rural), el área metropolitana de Montevideo, el ordenamiento costero, los planes departamentales y los instrumentos de gestión del suelo, y las perspectivas ante el cambio climático y la equidad territorial.

**Nivel**: Tier 2 — actualización trimestral
**Archivos**: 7 archivos temáticos + este README
**Solapamiento principal evitado**: vivienda-uy (políticas de vivienda específicas), medio-ambiente-uy (gestión ambiental general), infraestructura-uy (obras de infraestructura), departamentos-uy (descripción general de cada departamento)

## Criterios de actualización (Tier 2 — trimestral)

Actualizar cuando:
- DINOT emite nuevas Directrices Nacionales o aprueba planes departamentales
- Se aprueban nuevos planes locales o modificaciones de planes existentes
- INE publica datos de crecimiento urbano (proyecciones, censos)
- Se producen cambios regulatorios en el marco de la Ley 18.308
- Nuevos proyectos de urbanización o reconversión de gran escala son aprobados
- Estudios sobre cambio climático y territorio en Uruguay

## Reglas de solapamiento

Este dominio cubre **planificación y ordenamiento del territorio** como política pública. No cubre:
- **vivienda-uy**: la política de vivienda (MVOT, BHU, cooperativas) se cubre en vivienda-uy; este dominio cubre el marco de ordenamiento del suelo en el que se inserta la vivienda
- **medio-ambiente-uy**: la política ambiental general; este dominio cubre el ordenamiento costero y la gestión de suelos de protección
- **infraestructura-uy**: las grandes obras de infraestructura (represas, plantas de tratamiento); este dominio cubre la planificación del uso del suelo
- **departamentos-uy**: la descripción general de cada departamento; este dominio cubre el sistema de planificación territorial aplicado en el territorio
- **turismo-uy**: el turismo en general; este dominio cubre el ordenamiento de las zonas turísticas como parte de la planificación territorial
