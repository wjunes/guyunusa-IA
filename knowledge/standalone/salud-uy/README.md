# salud-uy

Dominio del conocimiento sobre **salud pública y sistema sanitario en Uruguay** para la Base Nacional de Conocimiento (BNC-UY).

## Descripción

Cubre el Sistema Nacional Integrado de Salud (SNIS), la reforma de 2007, las instituciones (MSP, ASSE, FONASA, JUNASA), el mutualismo, los niveles de atención, epidemiología, enfermedades, salud mental, salud materna, vacunación, emergencias sanitarias, derechos de usuarios y formación de profesionales.
