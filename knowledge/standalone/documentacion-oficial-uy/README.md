# documentacion-oficial-uy

Dominio transversal del BNC-UY sobre documentación oficial del Estado uruguayo.

## Descripción

Este dominio centraliza el conocimiento sobre los sistemas, instituciones y procedimientos que rigen la producción, publicación, registro y archivo de la documentación oficial en Uruguay. Actúa como ancla de trazabilidad normativa para todos los demás dominios del BNC-UY, proporcionando el marco de referencia para citar leyes, decretos, resoluciones y demás actos administrativos.

La institución central de este dominio es la **Dirección Nacional de Impresiones y Publicaciones Oficiales (IMPO)**, persona jurídica de derecho público no estatal, responsable del Diario Oficial, el Registro Nacional de Leyes y Decretos y el Banco Electrónico de Datos Jurídico-Normativos.

## Rol transversal en el BNC-UY

Este dominio es referenciado por todos los demás dominios del BNC-UY cuando citan normativa. El archivo `11-metodologia-de-referencias-para-bnc-uy.md` define el estándar de citación que debe aplicarse de forma consistente en toda la base de conocimiento.
