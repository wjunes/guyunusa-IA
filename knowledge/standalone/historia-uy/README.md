# historia-uy

Dominio BNC-UY: Historia del Uruguay

## Descripción

Documentación histórica de Uruguay desde el período colonial (siglo XVIII) hasta el presente (2026). Cubre los grandes períodos, procesos, figuras y eventos que configuraron el Estado y la identidad nacional uruguaya. Orientado a contextualización histórica, investigación y soporte de consultas sobre el pasado uruguayo.
