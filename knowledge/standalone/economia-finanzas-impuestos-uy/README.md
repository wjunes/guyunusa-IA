# economia-finanzas-impuestos-uy

Dominio del BNC-UY (Base Nacional de Conocimiento Uruguay) dedicado a la economía, las finanzas públicas, el sistema financiero, la política económica y el sistema tributario de la República Oriental del Uruguay.

## Descripción

Este dominio documenta integralmente la evolución económica del Uruguay, sus instituciones fiscales y financieras, la política macroeconómica, el sistema tributario, los principales indicadores económicos y los organismos responsables de la administración económica del Estado.

El contenido NO constituye asesoramiento tributario, contable ni financiero. Tiene exclusivamente propósito documental, educativo e informativo, orientado a sistemas RAG, investigadores, docentes, estudiantes y profesionales.
