# medio-ambiente-uy

Dominio del conocimiento sobre **medio ambiente y ecología en Uruguay** para la Base Nacional de Conocimiento (BNC-UY).

## Descripción

Cubre el marco institucional, la política ambiental, los ecosistemas naturales, la biodiversidad, los recursos hídricos, la transición energética, los desafíos de contaminación y la educación ambiental del Uruguay.
