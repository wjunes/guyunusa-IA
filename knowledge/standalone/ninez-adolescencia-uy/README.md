# Dominio BNC-UY: nineza-adolescencia-uy

## Descripción general

Dominio de conocimiento sobre los derechos, políticas e instituciones vinculadas a la niñez y adolescencia en Uruguay. Cubre el marco jurídico (CDN, Código de la Niñez), el INAU y el sistema de protección, primera infancia (CAIF, Uruguay Crece Contigo), educación, salud, trabajo infantil, violencia contra NNA, sistema penal adolescente (INISA), adopción y acogimiento, pobreza y vulnerabilidad, discapacidad, participación, historia institucional, niñez migrante e indicadores de situación.

**Nivel**: Tier 1 — actualización mensual (políticas sociales con cambios frecuentes)
**Archivos**: 15 archivos temáticos + este README
**Solapamiento principal evitado**: educacion-uy (política educativa general), salud-uy (sistema de salud general), mipymes-emprendimiento-uy, juventud-uy (18-29 años), envejecimiento-adulto-mayor-uy

## Criterios de actualización (Tier 1 — mensual)

Actualizar cuando:
- INAU publica datos de cobertura CAIF, centros residenciales o adopciones
- MSP reporta cambios en indicadores de salud infantil o vacunación
- ANEP reporta datos de matriculación, repetición o desvinculación
- INE publica datos de pobreza (ECH) con desagregación por edad
- Se aprueba o modifica legislación relevante para NNA
- INISA reporta datos del sistema penal adolescente
- UNICEF Uruguay publica informe de situación

## Reglas de solapamiento

Este dominio cubre **NNA (0-17 años)** y las políticas específicas dirigidas a este grupo etario. No cubre:
- **juventud-uy**: cubre el grupo 18-29 años (INJU, primer empleo joven, NiNi)
- **educacion-uy**: la política educativa general (ANEP, reforma educativa, docentes) está en educacion-uy; este dominio cubre el acceso y la situación educativa de los NNA
- **salud-uy**: el sistema de salud general está en salud-uy; este dominio cubre la salud específica de la niñez y adolescencia
- **envejecimiento-adulto-mayor-uy**: cubre adultos mayores (60+)
- **medio-ambiente-uy**: no incluye impacto ambiental en la infancia como tema central
- **genero-uy**: la violencia basada en género se documenta en genero-uy; este dominio cubre el impacto específico en NNA y el SIPIAV
