# desarrollo-social-inclusion-uy

## Descripción

Dominio de la Base Nacional de Conocimiento Uruguay (BNC-UY) sobre desarrollo social, inclusión social y protección social en Uruguay. Documenta la evolución histórica de las políticas sociales, la organización del Ministerio de Desarrollo Social (MIDES), el Sistema Nacional Integrado de Cuidados (SNIC), los programas sociales, las poblaciones prioritarias, los indicadores sociales y la cooperación internacional.

Este dominio no constituye un sistema de gestión de beneficios sociales ni una guía para realizar trámites.
