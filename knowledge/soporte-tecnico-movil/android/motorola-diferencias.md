# Android Motorola — Diferenciaciones My UX

## Sistema operativo
Android con My UX (Motorola). Aplica a Motorola Moto G, Edge, Razr y familia One.

## Descripción
Referencia de rutas de menú y características de Motorola (My UX) que difieren del Android estándar. Motorola es el fabricante que más se aproxima al Android puro (stock); las diferencias son menores pero relevantes en soporte técnico.

## Rutas de menú específicas de Motorola

### Ajustes principales
| Función estándar Android | Ruta en Motorola (My UX) |

| Acerca del teléfono | Ajustes → Acerca del teléfono |

| Opciones de desarrollador | Ajustes → Sistema → Opciones de desarrollador |

### Moto Actions (gestos exclusivos)
Motorola incorpora gestos que pueden confundirse con comportamientos erróneos:
- **Girar dos veces para abrir la cámara:** puede activarse accidentalmente. Ajustes → Moto / Aplicación Moto → Moto Actions → Torsión rápida.
- **Agitar dos veces para linterna:** Ajustes → Moto → Moto Actions → Toque rápido.
- **Voltear para silenciar:** voltear el teléfono boca abajo silencia las llamadas entrantes.

**Si el usuario reporta que la cámara o la linterna se activan solas:**
- Verificar y desactivar los Moto Actions correspondientes.

### Modo seguro en Motorola
- Mantener pulsado el botón de encendido → mantener pulsado "Apagar" hasta que aparezca "Reiniciar en modo seguro" → confirmar.

### Modo Recovery en Motorola
- Apagar el dispositivo.
- Encender manteniendo pulsado **Encendido + Bajar volumen** → accede al menú Bootloader.
- En el menú Bootloader: usar los botones de volumen para seleccionar "Recovery" → confirmar con el botón de encendido.

### Características exclusivas relevantes en soporte
- **Motorola Moto Display / Peek Display:** muestra notificaciones en pantalla apagada con animación. Si el usuario reporta que "la pantalla se enciende sola", puede ser esta función.
  - Desactivar: Ajustes → Pantalla → Pantalla Moto / Peek Display.
- **Ready For (modos Desktop/TV en modelos Edge):** conecta el teléfono a monitor externo. Puede alterar la resolución y comportamiento del sistema.
- **Motorola sin cargador en caja:** los modelos recientes no incluyen cargador; el usuario puede estar usando uno incompatible que cause carga lenta o problemas de batería.

## Advertencias
- Motorola es el fabricante más cercano a Android puro: la mayoría de rutas de Android estándar funcionan directamente.
- Las diferencias principales están en los Moto Actions y en la app Moto (gestos y personalización).
- Los modelos de gama media Moto G pueden recibir solo 2 años de actualizaciones de seguridad: verificar si el modelo sigue siendo compatible.
