# Android Samsung — Diferenciaciones One UI

## Sistema operativo
Android con One UI (Samsung). Aplica a Samsung Galaxy S, A, M, Z y Tab con One UI 4.x, 5.x y 6.x.

## Descripción
Referencia de rutas de menú y características exclusivas de Samsung One UI que difieren del Android estándar. Complementa los documentos generales de Android cuando el usuario tiene un dispositivo Samsung.

## Rutas de menú específicas de One UI

### Ajustes principales
| Función estándar Android | Ruta en One UI (Samsung) |
|---|---|
| Acerca del teléfono | Ajustes → Acerca del teléfono → Información de software |
| Número de compilación | Ajustes → Acerca del teléfono → Información de software → Número de compilación |
| Opciones de desarrollador | Ajustes → Opciones de desarrollador (aparece al final de Ajustes tras activar) |
| Actualización del sistema | Ajustes → Actualización de software |
| Batería | Ajustes → Batería y cuidado del dispositivo → Batería |
| Almacenamiento | Ajustes → Batería y cuidado del dispositivo → Almacenamiento |
| Diagnóstico del dispositivo | Ajustes → Batería y cuidado del dispositivo → Diagnóstico del dispositivo |
| Aplicaciones | Ajustes → Aplicaciones |
| Permisos de app | Ajustes → Aplicaciones → [app] → Permisos |
| Red móvil | Ajustes → Conexiones → Redes móviles |
| Wi-Fi avanzado | Ajustes → Conexiones → Wi-Fi → [red] → (ℹ) |
| Bluetooth | Ajustes → Conexiones → Bluetooth |
| NFC | Ajustes → Conexiones → NFC y pagos sin contacto |
| Punto de acceso | Ajustes → Conexiones → Módem y zona Wi-Fi |
| Sonido avanzado | Ajustes → Sonido → Calidad de sonido y efectos |
| Sensibilidad táctil | Ajustes → Pantalla → Sensibilidad táctil |

| Restablecimiento de fábrica | Ajustes → Administración general → Restablecer → Restablecer datos de fábrica |

### Cuenta Samsung (Samsung Account)
- Ajustes → [nombre / Samsung Account] → gestión de cuenta Samsung.
- Permite acceder a Samsung Find My Mobile (localización y desbloqueo remoto).
- Independiente del Google Account: Samsung tiene su propio sistema de recuperación.

### Find My Mobile (Samsung)
- URL: https://findmymobile.samsung.com
- Permite desbloquear el patrón o PIN de forma remota si la cuenta Samsung está vinculada.
- Requiere que el dispositivo esté encendido y conectado a Internet.

### Modo seguro en Samsung
- Mantener pulsado el botón lateral → mantener pulsado el ícono de "Apagar" → confirmar Modo seguro.

### Modo Recovery en Samsung
- Apagar el dispositivo → Encendido + Subir volumen (+ botón Bixby en modelos con Bixby físico) → mantener hasta ver el logo Samsung → soltar.
- Navegar con botones de volumen, seleccionar con el botón lateral.

### Diagnóstico integrado (Samsung Members / *#0*#)
- App Samsung Members → Soporte → Diagnóstico → permite probar pantalla, altavoz, micrófono, cámara, sensores.
- Código de marcación rápida: *#0*# (solo en algunos modelos Galaxy) → menú de diagnóstico de hardware.

### Características exclusivas relevantes en soporte
- **Edge Panels:** paneles laterales que pueden confundirse con errores de pantalla si no se conocen.
- **Burstón y DeX:** modos especiales que alteran el comportamiento de la pantalla y apps.
- **Good Lock:** app de personalización de Samsung que puede causar comportamientos no estándar si está instalada.
- **Game Booster:** puede limitar el rendimiento o la red en modo de juego aunque no se esté jugando.

## Advertencias
- Las rutas de One UI pueden variar entre versiones (One UI 4, 5, 6): si no se encuentra una opción, buscar por nombre en el buscador de Ajustes.
- Samsung Account y Google Account son independientes: problemas con uno no afectan al otro.
- Find My Mobile de Samsung es independiente de Find My Device de Google.
