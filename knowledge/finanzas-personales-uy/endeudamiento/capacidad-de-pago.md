# Capacidad de pago

## ¿Qué es?

La capacidad de pago es el monto máximo que una persona o familia puede destinar al pago de deudas cada mes sin comprometer los gastos básicos ni su estabilidad financiera. Es el número más importante antes de asumir cualquier nueva obligación: un crédito, una tarjeta, una compra en cuotas.

Conocer la capacidad de pago antes de endeudarse permite tomar decisiones basadas en la realidad, no en el entusiasmo del momento.

## ¿Para qué sirve saber esto?

Las instituciones financieras evalúan la capacidad de pago antes de otorgar un crédito. Pero esa evaluación está hecha desde el interés del prestamista, no necesariamente desde el bienestar del deudor. La institución puede prestar lo máximo que técnicamente pueda cobrarse; la persona debe saber lo máximo que puede pagar cómodamente, que no siempre coincide.

## Conceptos clave

- **Capacidad de pago:** ingresos disponibles menos gastos esenciales = lo que realmente puede destinarse a nuevas deudas.
- **Ratio de endeudamiento:** porcentaje de los ingresos que ya está comprometido en deudas. Se calcula: (total cuotas actuales / ingresos netos) × 100.
- **Regla del 30%:** referencia ampliamente usada: no destinar más del 30% de los ingresos netos al pago de deudas (algunas fuentes usan el 35-40% como máximo, pero con mayor riesgo). Superado ese umbral, cualquier imprevisto puede generar problemas de pago.
- **Ingreso disponible:** ingreso neto menos gastos esenciales fijos (alquiler, servicios, alimentación básica). Es la base real para calcular qué cuota se puede asumir.

## En Uruguay

En Uruguay el Banco Central del Uruguay (BCU) y la COPAB promueven la educación financiera responsable. Las instituciones financieras habilitadas deben evaluar la capacidad de pago del solicitante antes de otorgar crédito. Si una institución otorga crédito sin verificar la capacidad de pago del usuario, puede existir una práctica de crédito irresponsable denunciable ante la COPAB o la Defensa del Consumidor.

La **Central de Riesgos del BCU (SIIF)** registra el historial crediticio de las personas. Tener cuotas impagas afecta este registro y puede dificultar futuros créditos.

## Cómo calcularla

**Fórmula simplificada:**

```
Capacidad de pago = (Ingresos netos × 30%) − Cuotas actuales
```

Si el resultado es positivo: hay margen para una nueva deuda hasta ese monto.
Si el resultado es cero o negativo: no hay capacidad para asumir nuevas obligaciones.

**Pasos:**
1. Calcular los ingresos netos mensuales (lo que efectivamente entra).
2. Multiplicar por 0,30 (30%) para obtener el límite máximo recomendado para deudas.
3. Restar las cuotas que ya se están pagando (préstamos, tarjetas, compras en cuotas).
4. El resultado es el margen disponible para una nueva deuda.

## Ejemplo práctico

> Números ilustrativos en pesos uruguayos ($).

**Situación:**
Ingresos netos: $60.000
Cuotas actuales: $18.000
Nueva cuota propuesta: $12.000

**Análisis:**

| Concepto | Monto |
|---|---|
| Ingresos netos | $60.000 |
| 30% de ingresos (límite recomendado) | $18.000 |
| Cuotas actuales | $18.000 |
| Margen disponible para nueva deuda | **$0** |
| Si se agrega la nueva cuota de $12.000 | |
| Total cuotas: $18.000 + $12.000 | $30.000 |
| Porcentaje comprometido | **50%** |
| Dinero restante para vivir | $30.000 |

**Conclusión:**
Esta persona ya está en el límite del 30% con las deudas actuales. Agregar una cuota de $12.000 llevaría el endeudamiento al 50% del ingreso. Eso significa que de cada $2 que gana, $1 va al pago de deudas. Con $30.000 para cubrir alquiler, comida, transporte y servicios (que en muchos casos ya superan esa cifra), el riesgo de incumplimiento es alto.

Antes de aceptar esa nueva cuota, hay que preguntarse: ¿es imprescindible? ¿hay alternativa? ¿se puede reducir el monto o el plazo?

## Señales de alerta

- El ratio de endeudamiento ya supera el 30% y se está evaluando asumir más deuda.
- Para calcular la "capacidad de pago" se está usando el ingreso bruto en lugar del neto.
- Se incluyen ingresos eventuales o inciertos como base del cálculo.
- No se está contabilizando todas las cuotas actuales (se olvida la tarjeta, las cuotas chicas, etc.).

## Cuándo consultar a un profesional

Si el ratio de endeudamiento ya supera el 40-50% y hay dificultades para pagar, es recomendable consultar con un asesor financiero o contador antes de asumir cualquier nueva obligación. Si ya hay moras o embargos, puede necesitarse asesoramiento legal.
